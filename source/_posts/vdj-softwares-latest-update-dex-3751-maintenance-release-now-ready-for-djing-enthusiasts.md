## VDJ Software's Latest Update: DEX 3.7.5.1 Maintenance Release Now Ready for DJing Enthusiasts!

**A maintenance release for our top DJ and video mixing software is available for download**

[LEARN MORE ABOUT DEX 3 ![](https://i2.wp.com/pcdj.com/wp-content/uploads/2016/11/dex3-onlaptop-controller.jpg?fit=300%2C187&ssl=1 "dex3-onlaptop-controller")](https://tools.techidaily.com/pcdj/products/)

Version 3.7.5.1 is a free update for [DEX 3](https://tools.techidaily.com/pcdj/products/) DJs and can be downloaded now below. The 3.7.5.1 update includes a handful of minor bug fixes and performance improvements, and utilizes the latest [Pulselocker](https://tools.techidaily.com/pcdj/products/) streaming subscription service [SDK](https://en.wikipedia.org/wiki/Software%5Fdevelopment%5Fkit).

The updated [Pulselocker](https://tools.techidaily.com/pcdj/products/) SDK used in DEX 3.7.5.1 fixes a few small nuances subscribers reported, but more importantly an issue that would prevent some songs from streaming (offline playback was not affected).

[LEARN MORE ABOUT PULSELOCKER ![Pulselocker Logo In Black](https://i0.wp.com/pcdj.com/wp-content/uploads/2015/10/pulselocker-logo_h_black.png?fit=216%2C174&ssl=1 "Pulselocker Logo In Black")](https://tools.techidaily.com/pcdj/products/)

[Pulselocker](https://tools.techidaily.com/pcdj/products/) is a popular music online/offline subscription service for [DEX 3](https://tools.techidaily.com/pcdj/products/) users and provides in-app access to a massive catalog of commercially legal music. Performance when using the service within DEX 3.7.5.1 should be better than in any past iteration, and subscribers can DJ confidently online or offline (using a pro-tier subscription).

The PCDJ development team is happily hammering (keys) away in the bat cave working on DEX 3.8, which promises to include [new game breaking features](https://tools.techidaily.com/pcdj/products/) to help improve your live mixing performances. We suggest you download the 3.7.5.1 maintenance release in the meantime!

#### Changes And Updates In DEX 3.7.5.1

* Updated to include the latest Pulselocker SDK (fixes random streaming issue reported by some subscribers)
* Minor bug fixes and performance improvements
